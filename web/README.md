# web/

Browser front ends. Framework ownership is isolated: React shell,
TypeScript telemetry custom element, and an artifact inspector rendered
by the Ruby service.

| Directory | Purpose | Milestone |
| --- | --- | --- |
| `shell-react/` | React Flow process-graph shell | 10 |
| `telemetry-angular/` | TypeScript Web Component telemetry panel (`<rg-telemetry-panel>`) | 10 |
| `shared-contracts/` | Shared browser-side types and SSE parsing | 10 |
