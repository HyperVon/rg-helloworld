# observability/

Local observability stack: OpenTelemetry Collector, Prometheus, Loki, Tempo,
and Grafana.

| Directory | Purpose | Milestone |
| --- | --- | --- |
| `dashboards/` | Grafana dashboard JSON (Overview, Run Deep Dive, OCR Lab, Infra) | 11 |
| `alerts/` | In-dashboard local alerts | 11 |
| `otel/` | Collector configuration (OTLP intake, routing) | 11 |
| `prometheus/` | Scrape configuration | 11 |
| `loki/` | Loki configuration | 11 |
| `tempo/` | Tempo configuration | 11 |
