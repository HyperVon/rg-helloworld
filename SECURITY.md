# Security

This project runs entirely on one local laptop with no external services.
It is a demonstration project; do not deploy it to shared or public
environments.

## Reporting issues

The repository contains no secrets, credentials, or production
configuration. If you find a security-relevant problem (for example,
credentials in logs or artifacts, or the anti-cheating boundary being
bypassable), open a private issue through the repository's security
reporting path rather than a public issue.
