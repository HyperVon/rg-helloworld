# Agent instructions

This file is the thin universal entrypoint for this repository. Canonical
guidance lives under `.agents/`.

1. Read [`.agents/AGENTS.md`](.agents/AGENTS.md) for product boundaries,
   invariants, and skill routing.
2. Read [`.agents/OPERATING.md`](.agents/OPERATING.md) for always-on operating
   norms.
3. When a task matches a skill, read and follow
   `.agents/skills/<name>/SKILL.md`.
