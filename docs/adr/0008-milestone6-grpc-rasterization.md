# ADR-0008: Milestone 6 gRPC rasterization

- Status: Accepted
- Date: 2026-08-05

## Context

Milestone 6 adds the C#/.NET rasterizer (architecture Stage 4): it receives
normalized em-square segments over gRPC and returns PNG artifacts stored in
MinIO. Four decisions shape the implementation:

1. Which local rendering library to use (Stage 4 permits "SkiaSharp or an
   equivalent local rendering library").
2. How generated gRPC code is produced and versioned.
3. The `go_package` option of the shared proto contract.
4. How the plaintext h2c transport between the Go normalizer and the C#
   service is enabled.

## Decision

### Rendering library: ImageSharp (not SkiaSharp)

`SixLabors.ImageSharp` 3.1.12 + `SixLabors.ImageSharp.Drawing` 2.1.7 render
the glyphs. ImageSharp is pure managed code: no native binaries to pin per
platform (SkiaSharp needs per-OS native assets, and its macOS arm64 support
is uneven), deterministic on the same platform, and fully covered by the
C# unit tests. Rendering is resolution-independent: stroke width and
coordinates are expressed in the 1024-unit em-square and mapped onto the
request canvas, so render profiles survive canvas changes.

### Committed generated code, pinned toolchains

- Go: generated client code is committed under
  `services/vector-normalizer-go/internal/rasterproto/` and regenerated by
  `scripts/gen-proto.sh` (protoc 35.1 + protoc-gen-go v1.36.11 +
  protoc-gen-go-grpc v1.6.2, all pinned in `versions.env`); `make contracts`
  regenerates and `proto-gen-check` detects drift in CI. Generated code is
  excluded from the Go coverage profile (mirroring the C++ gcovr excludes).
- C#: message + service code is committed under
  `services/rasterizer-dotnet/generated/` and regenerated by
  `scripts/gen-csharp-proto.sh`. Grpc.Tools ships no macOS-arm64
  protoc/plugin (verified for 2.81.1..2.83.0), so on arm64 macOS the codegen
  runs in the pinned `mcr.microsoft.com/dotnet/sdk:10.0.302` container and
  natively on x86_64 Linux (CI). Generated code is excluded from the
  coverlet gate (`ExcludeByFile`) and from `dotnet format`
  (`generated_code = true` in `generated/.editorconfig`).

### Contract change: `go_package` and `input_artifact_sha256`

The proto's `go_package` moved from `rghello.dev/rasterizer/proto/...` (a
module that does not exist in this repository) to
`rghello.dev/vector-normalizer/internal/rasterproto;rasterproto`, the
package of the only Go consumer. `RenderGlyphRequest` gained
`input_artifact_sha256 = 10`: the SHA-256 of the input normalized artifact,
used as the §13.5 idempotency input hash. The C# service derives the
operation ID from `runId`, `rasterize-glyph`, `glyphInstanceId`, `attempt`,
and `inputArtifactSha256`, embeds it in the PNG object key, and derives the
artifact UUID from it; the Go normalizer computes the same operation ID, so
event IDs and artifact keys are stable across duplicate requests. The
`transformation.name` (`rasterize-glyph`) matches the
`glyph-rasterized.v1` schema.

### Cleartext HTTP/2

The Go client uses plaintext h2c (insecure credentials; internal traffic).
Kestrel in .NET 10 only serves cleartext HTTP/2 when the endpoint is
HTTP/2-only: with `HttpProtocols.Http1AndHttp2` and no TLS,
`SelectProtocol` always returns HTTP/1 (the AppContext switch from .NET 9
no longer exists in the .NET 10 assembly). The server therefore binds
`ListenAnyIP(port, listen => listen.Protocols = HttpProtocols.Http2)`.

## Consequences

- The rasterizer never receives the phrase, expected character, or code
  point; its request carries only segments, canvas/profile, and opaque
  identifiers, and the §7.4 prohibited-field scans cover its events.
- Deterministic artifacts: identical requests produce the same object key
  and byte-identical PNGs (unit + integration verified).
- Contract changes require regenerating both Go and C# clients
  (`make contracts` runs both scripts); `proto-gen-check` and
  `gen-csharp-proto.sh --check` guard drift in CI.
- The Go module's coverage gate excludes the generated `rasterproto`
  package; hand-written rasterizer code stays measured at >= 90%.
